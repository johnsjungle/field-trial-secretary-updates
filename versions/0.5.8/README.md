# HALO v0.5.8

HALO v0.5.8 adds a pink Trial Guide warning and a review popup before preliminary draws when hounds have changed stakes, late entries are missing, or the running order needs updating. It also brings the previous Windows release's corrected stake results, combined scores, placements, record sheets, and startup fixes to macOS and Ubuntu.

Existing installations can update from **Admin > Updates & Versions**. The updater backs up and preserves the local trial database while replacing program files and restarting HALO.

Download installers from the [v0.5.8 release](https://github.com/johnsjungle/field-trial-secretary-updates/releases/tag/v0.5.8):

- Windows: extract the portable ZIP and run **Start HALO.vbs**.
- Apple Silicon Mac: use the **arm64** DMG.
- Intel Mac: use the **x86_64** DMG.
- Ubuntu: install the **amd64.deb** package or make the **x86_64.AppImage** executable and run it.

New installations include a blank starter database template and no live trial data. On first launch, choose to create a new database or restore an existing one.

See [RELEASE_NOTES.md](RELEASE_NOTES.md) for the changes included in this version.
