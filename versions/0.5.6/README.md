# HALO v0.5.6

HALO v0.5.6 is a Windows release that adds safe stake corrections after preliminary scoring and fixes a startup problem that could leave the application on its loading screen.

Existing Windows installations can install it from **Admin > Updates & Versions**. The updater backs up and preserves the local trial database, replaces the program files, and restarts HALO.

For a new Windows installation, download the portable ZIP from the [v0.5.6 GitHub release](https://github.com/johnsjungle/field-trial-secretary-updates/releases/tag/v0.5.6), extract it, and run **Start HALO.vbs**.

macOS and Ubuntu packages are not part of this release and will be published separately.

See [RELEASE_NOTES.md](RELEASE_NOTES.md) for the improvements included in this version.
