# Field Trial Secretary v0.4.1 beta

Offline lure-coursing trial management for Windows and macOS, with AKC and ASFA split-stake overrides.

Packaged v0.4.0 users: open Admin > Updates & Versions, check online, select Prepare Update for v0.4.1, then Install and Restart. The updater verifies the download, backs up SQLite, and preserves trial data while replacing program files.

Users on older versions or source installations: back up the database, close the application, and install manually. Public installers contain no live trial data.

Use Roll Call > Advanced: Split Stakes for per-breed overrides in the current trial. Enter the minimum and a reason, or reset to automatic. Changes require rebuilding an existing draw before scoring.
