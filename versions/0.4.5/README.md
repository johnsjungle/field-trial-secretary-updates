# Field Trial Secretary v0.4.5 beta

Offline lure-coursing trial management for Windows and macOS.

This release restores **Create Final Archive & Lock Trial** and improves SQLite connection cleanup on Windows. Existing v0.4.4 installations can install it with **Admin > Updates & Versions > Check Online**, then **Update Program to v0.4.5**. The updater backs up the current database, updates only program files, and restarts the application.

Users on v0.4.3 or older can install v0.4.4 or v0.4.5 manually. Existing trial data remains in its current data directory.

See [release notes](RELEASE_NOTES.md).
