# Field Trial Secretary v0.4.2 beta

Offline lure-coursing trial management for Windows and macOS, with clearer multi-field paperwork, flexible roll-call printing, and contextual guidance.

Packaged v0.4.0 or newer users: open Admin > Updates & Versions, check online, select Prepare Update for v0.4.2, then Install and Restart. The updater verifies the download, backs up SQLite, and preserves trial data while replacing program files.

Users on older versions or source installations: back up the database, close the application, and install manually. Public installers contain no live trial data.

This release adds expandable help, searchable issue guidance, field and lane roll-call formats, field-separated draw and judge packets, clearer field headings, and AKC packet corrections.

See [release notes](RELEASE_NOTES.md).
