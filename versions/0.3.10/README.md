# Field Trial Secretary v0.3.10 beta

Offline lure-coursing trial management for Windows and macOS. Includes specialty stakes, multi-day BIE setup, optional elimination rounds, and AKC/ASFA paperwork.

Close the existing app and back up its database before updating. Public installers contain no live trial data.

See [release notes](RELEASE_NOTES.md) for the changes in this version.
