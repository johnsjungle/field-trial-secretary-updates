# Field Trial Secretary v0.4.3 beta

Offline lure-coursing trial management for Windows and macOS, with expanded Best in Event management for multi-day and Grand Prix-style events.

Packaged v0.4.0 or newer users: open Admin > Updates & Versions, check online, select Prepare Update for v0.4.3, then Install and Restart. The updater verifies the download, backs up SQLite, and preserves trial data while replacing program files.

Users on older versions or source installations: back up the database, close the application, and install manually. Public installers contain no live trial data.

This release adds multi-trial qualification, a breed pre-qualifier, up to six judges, balanced course draws, runner confirmation, record sheets, previous-round corrections, and safer Undo behavior.
