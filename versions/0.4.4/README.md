# Field Trial Secretary v0.4.4 beta

Offline lure-coursing trial management for Windows and macOS, with safer installation and automatic application updates.

Packaged v0.4.0 through v0.4.3 users: open Admin > Updates & Versions, check online, prepare v0.4.4, then choose Install and Restart. After v0.4.4 is installed, future updates use one **Update Program** action.

New installations contain no live trial database. On first launch, create a new empty database or restore an existing Field Trial Secretary SQLite database. Existing installations keep their current database automatically.

Users on older versions or source installations can back up their database, close the application, and install manually.

See [release notes](RELEASE_NOTES.md).
