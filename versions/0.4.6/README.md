# Field Trial Secretary v0.4.6 beta

Offline lure-coursing trial management for Windows and macOS.

This release adds the complete AKC JC/QC workflow, including independent test entry and scoring, official test record sheets, individual QC certificates, and a prefilled Judges' Book cover. Existing installations can install it with **Admin > Updates & Versions > Check Online**, then **Update Program to v0.4.6**. The updater backs up the current database, updates only program files, and restarts the application.

Manual installers are also available below. Existing trial data remains in its current data directory.

See [release notes](RELEASE_NOTES.md).
