# Field Trial Secretary v0.4.0 beta

Offline lure-coursing trial management for Windows and macOS, now with built-in application updating.

Install v0.4.0 manually once to gain the updater for subsequent releases. Back up the existing database and close the application before this initial installation. Public installers contain no live trial data.

For future updates, open Admin > Updates & Versions, check online, select Prepare Update, then Install and Restart. The packaged app verifies the download, backs up SQLite, and preserves trial data while replacing program files. Source installations use manual updates.

See [release notes](RELEASE_NOTES.md).
