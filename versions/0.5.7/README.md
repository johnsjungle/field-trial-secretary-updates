# HALO v0.5.7

HALO v0.5.7 is a Windows release that corrects the on-screen Results page and ASFA record sheets after a hound changes stakes between preliminary and final scoring.

Existing Windows installations can install it from **Admin > Updates & Versions**. The updater backs up and preserves the local trial database, replaces the program files, and restarts HALO.

For a new Windows installation, download the portable ZIP from the [v0.5.7 GitHub release](https://github.com/johnsjungle/field-trial-secretary-updates/releases/tag/v0.5.7), extract it, and run **Start HALO.vbs**.

macOS and Ubuntu packages are not part of this release and will be published separately.

See [RELEASE_NOTES.md](RELEASE_NOTES.md) for the improvements included in this version.
