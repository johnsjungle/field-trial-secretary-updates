# HALO v0.5.4

HALO v0.5.4 is a stable specialty-pairing release for Windows, macOS, and Ubuntu.

Existing HALO installations can install it from **Admin Tools > Check for Updates**. The updater preserves the local trial database and restarts HALO after replacing the program files.

For a new installation, download the file for your operating system from the v0.5.4 GitHub release. Ubuntu users can choose the `.deb` package or portable AppImage.

See [RELEASE_NOTES.md](RELEASE_NOTES.md) for the improvement included in this version.
